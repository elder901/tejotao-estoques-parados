# Inventory Action Plan

eu preciso de software onde varios usuarios vão entrar e definir um plano de ação unico para estoques parados, esse software é destinado aos compradores do Supermercado Tejotão, cada comprador cuida de um departamento, então é importante ter filtros de unidades, departamento e muito importante ter filtro de fornecedores, quando selecionado o filtro esse software trará um ranking de top 50 ordenado por valor e mostrando os dias de estoque de cada itens, precido de um drill down no item com campos para prenecher o plano de ação, com responsaveis e as estrqtegias que serão feitas para gisrar esse item, nesse drildown precisa ter o resumo do item, com as informações, será um sistema multi usuario, consegue me ajudar?
